# Association Between APOE4 Carrier Status and Web-based Central Hearing Performance

This repository contains the code, data, and documentation for a research project investigating the relationship between the APOE4 allele and remote hearing performance. The study is a secondary analysis of data from the Great Minds dementia cohort.

### Repository Structure

* `docs/`: Contains project documentation.
* `notebooks/`: Contains Jupyter notebooks with the data analysis code and a narrative of the findings.
* `data/`: Contains the raw and processed data files.
* `figures/`: Contains any generated plots or visualisations.
