# Association Between APOE4 Carrier Status and Web-based Central Hearing Performance

This repository contains the code, data, and documentation for a research project investigating the relationship between the APOE4 allele and remote hearing performance. The study is a secondary analysis of data from the Great Minds dementia cohort.

### 1. Research Questions

This project seeks to answer the following questions:

* **Is there a significant association between APOE4 status and web-based central hearing performance in older adults?**
* **Is there a significant association between APOE ε4 carrier status and specific types of central hearing measures, such as speech-in-noise thresholds or auditory working memory precision?**
* **Does the relationship between age and hearing performance differ between APOE ε4 carriers and non-carriers?**

### 2. Project Aims

By exploring these questions, this project aims to provide potential insights into the early risk profiling of dementia by examining the link between a key genetic risk factor for Alzheimer's disease and hearing function.

### 3. Repository Structure

* `docs/`: Contains project documentation.
* `notebooks/`: Will contain Jupyter notebooks with the data analysis code and a narrative of the findings.
* `data/`: Will contain the raw and processed data files.
* `figures/`: Will contain any generated plots or visualizations.
